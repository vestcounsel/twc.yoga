# Standalone photos

Drop photos here that should run as **standalone posts** in the grid —
single photo posts interspersed between the carousels.

This folder is separate from `assets/photos/`, which holds photos that are
placed *inside* slides (e.g. the bio portrait). Anything in this folder is a
post of its own, not slide material.

## How to add a photo

1. Upload the image file directly into this folder (JPG or PNG).
2. Use a descriptive, lowercase, hyphenated filename, e.g.
   `studio-morning-light.jpg` or `2026-08-office-desk.png`.
3. Commit — nothing else is required yet.

## Sizing

The grid runs on 1080 × 1350 (4:5 portrait), the same size as the carousel
slides. Photos don't need to arrive pre-cropped — upload the original and
any cropping/framing can happen when the photo is prepared for posting —
but keep the long edge at 1080 px or more so nothing has to be upscaled.
